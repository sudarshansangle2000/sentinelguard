# SentinelGuard: APP Fraud Detection Engine for Irish Banking

**MSc Computer Science (Data Analytics) — University of Galway**
**Student:** Sudarshan Sangle (25234760)
**Supervisor:** Finlay Smith

## Project Overview
SentinelGuard is an XGBoost-based machine learning pipeline to detect
Authorised Push Payment (APP) fraud in Irish mobile banking transactions.

In 2024, the Central Bank of Ireland reported €160M in APP fraud losses
(40% YoY increase). This project addresses the gap: no existing model
combines Irish CBI statistical features with explainable multi-class
APP fraud detection.

## Tech Stack
- Python, XGBoost, SMOTE (imbalanced-learn), SHAP, Optuna
- Google Colab (training), Overleaf (paper writing)
- Dataset: PaySim (Kaggle) + Kaggle Credit Card Fraud
